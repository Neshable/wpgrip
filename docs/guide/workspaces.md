# Workspaces

Workspaces (also called tenants) are the top-level organizational unit in WPGrip. Each workspace has its own sites, SSH keys, team members, and billing.

## When to Use Multiple Workspaces

- **Agencies**: One workspace per client, or one workspace per internal team
- **Freelancers**: Separate personal projects from client work
- **Hosting companies**: Isolate customer environments

## Creating a Workspace

A default workspace is created when you sign up. To create additional workspaces:

1. Click the workspace switcher in the sidebar
2. Click **Create Workspace**
3. Enter a name and you’re ready to go

::: info
Each workspace requires its own subscription. Sites in workspace A don’t count against workspace B’s limits.
:::

## Switching Workspaces

Use the workspace switcher in the top-left corner of the dashboard. Your current workspace name and plan are always visible in the sidebar.

## Workspace Settings

Each workspace has independent settings:

- **SSH Keys** — unique key pair per workspace
- **Team Members** — invitations are workspace-scoped
- **Billing** — separate subscription per workspace
- **Notifications** — alert preferences for uptime, SSL, etc.
